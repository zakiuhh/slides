# Theme screenshot assets

This folder contains local PNG screenshots from the design gallery in
[`zarazhangrui/beautiful-html-templates`](https://github.com/zarazhangrui/beautiful-html-templates).
The files are named by template and slide number (for example,
`soft-editorial-4.png`). The root README displays a selected set of these
images; the remaining screenshots are kept here for future galleries.

Source gallery: [`screenshots/`](https://github.com/zarazhangrui/beautiful-html-templates/tree/main/screenshots)
